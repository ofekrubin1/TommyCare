🐣 TommyCare · מדיניות פרטיות

עודכן: אוקטובר 2026

TommyCare היא אפליקציה משפחתית פרטית לתיעוד הטיפול בתינוק (האכלות, חיתולים, שינה, תורים ומשימות). היא משמשת רק את בני המשפחה שקיבלו חשבון, ואין בה הרשמה פתוחה.

איזה מידע נשמר

הרישומים שבני המשפחה מזינים, שם תצוגה, וכתובות מייל לסיכום היומי. המידע נשמר ב-Google Firebase, ונגיש רק לחשבונות של המשפחה.

Google Calendar

כשמשתמש בוחר להוסיף תור או משימה ל-Google Calendar, האפליקציה מבקשת הרשאה ליומן שלו (calendar.events) ומשתמשת בה רק כדי: להוסיף, לעדכן או למחוק את האירועים שהמשתמש עצמו יצר מתוך האפליקציה, ולייבא תורים שכותרתם מתחילה בשם התינוק. ההרשאה ניתנת ישירות בדפדפן ונשמרת לזמן קצר בלבד (עד שעה). מידע מהיומן לא נשמר מעבר לתורים שיובאו, לא מועבר לאף גורם, ולא משמש לשום מטרה אחרת.

השימוש של TommyCare במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

Privacy Policy (English)

TommyCare is a private family app for logging a baby's care. Only family accounts can sign in; there is no public sign-up. Entries, display names and summary email addresses are stored in Google Firebase and are accessible only to the family's accounts.

Google Calendar. When a user chooses to add an appointment or task to Google Calendar, the app requests the calendar.events scope in the browser and uses it only to create, update or delete the events that user created from the app, and to import appointments whose title starts with the baby's name. Access tokens are short-lived (up to one hour) and are not stored on a server. Calendar data is not shared with anyone or used for any other purpose. TommyCare's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Notifications. If notifications are turned on, a push subscription for that device is stored and can be removed in Settings.
